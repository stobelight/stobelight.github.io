>I envision this website as a sort of social network for discovering, geotagging, and visualizing music (what i love to do). This demo shows core user functionality while being a learning project using cables.gl. In this shared virtual world, users playing a specific song would be in the same room and play with, maybe even create, reactive visuals collaboratively, able to communicate and visually recognize each other. The 'menu' for this 'game' would be the outer perspective of the globe where users discover and select songs based off geolocation and album art. A user would have a profile of personally saved geo-track data, with the ability to view other user's globe profile saved geo-tracks. This is again a prototype with many bugs, yet I am inspired to share my idea. Cheers to playing with iTunes visualizer and thanks to SoundCloud feed.



Made with https://cables.gl !
